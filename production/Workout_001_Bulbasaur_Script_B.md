**Primary hypothesis:** Version B increases engagement from Pokémon fans through recognisable in-game terminology without hurting first-time viewers' understanding. Version A may perform better with a broader fitness audience because its humor requires less familiarity.

### A/B test protocol

1. Record both dialogue tracks using the **same base edit** and the **same duration / framing**, only swapping the VO and matched captions.
2. Use the **same four exercise shots, supporting montage, cover, first frame, soundtrack, volume, main on-screen exercise/prescription labels, post caption, and CTA**. In particular, don't add extra “HP / PP” animations only to Version B in the initial test; they'd test additional graphic effects as well as comedy.
3. If the platform supports randomized or split-audience creative tests, use that for stronger evidence. Otherwise, post each version to comparable audiences/time slots and treat findings as directional, not definitive.
4. Compare **3-second hold rate**, **average watch time**, **completion rate**, **saves per 1,000 views**, **shares per 1,000 views**, and **visits/clicks to the Workout Pokédex per 1,000 views** where analytics permit.
5. Keep a log of date/time, platform, reach source, paid/organic distribution, and audience differences. Do not conclude one joke style is better from a small number of views or a posting-time advantage.
6. Ask whether the **workout information stayed clear** in both versions. A higher share rate is not worth viewers missing the actual movement names or doses.

### Optional, after initial test only
If Version B performs well, create an even more Pokémon-coded variant with small HP/PP UI gags; **do not mix this into the initial A/B**, as it changes more than dialogue.
